# Identité visuelle Double Interface

La nouvelle icône est incluse dans :

- `KoveMirror/Assets.xcassets/AppIcon.appiconset/icon_1024.png`
- `KoveMirror/Assets.xcassets/RideMark.imageset/ride-mark.png`

Le PNG a été exporté mécaniquement en **1024 × 1024, RGB opaque** pour Xcode. L’original généré est conservé en dehors de ce projet ; cette exportation ne change pas le dessin.

Création : génération d’image intégrée, puis retouche de l’image générée.

Brief final : conserver le fond ivoire, la montagne/route vert forêt, la flèche et le point orange ; ajouter deux écrans d’interface superposés derrière le symbole ; écrire **DOUBLE** puis **INTERFACE** sur deux lignes, en capitales grasses en bas à gauche ; ne pas dessiner le masque extérieur arrondi de l’icône iOS.
